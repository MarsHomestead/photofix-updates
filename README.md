# PhotoFix updates

Public update notes for the PhotoFix listing-photo bot. Each PhotoFix copy can check `updates.json` once a week, show its owner anything newer than what it has, and add those improvements only when the owner says yes.

## What moves through here

- Only bot setup information: tools, workflows, tips and recommendations you may want to add.
- No personal information, passwords, account details or private data is ever sent or received.
- An update never asks for personal information, logins or account access. If one ever did, your PhotoFix would ignore it and tell you.
- Everything happens only after your yes.
